\subsubsection{Gower dissimilarity}
\label{sec:measure:gower}

\paragraph{Overview}
\label{sec:measure:gower:overview}
Gower dissimilarity compares observations described by numeric, nominal,
binary and explicitly ordered features while retaining missing values.
Each pair is compared only on its available information. This provides
an alternative input to clustering when imputation would introduce values
that were not measured. Algorithm choice and data suitability are broader
clustering concerns discussed by Gatea et al.~\cite{ref_3}; the specific
missing-data behaviour here is established by the implementation and
experiments below. The component returns the complement of Gower's
similarity, not its square root.

\paragraph{Definition}
\label{sec:measure:gower:definition}
Gower (1971), \emph{Biometrics} 27(4), 857--871,
\href{https://doi.org/10.2307/2528823}{doi:10.2307/2528823}, is the original
source. For two observations, the implemented weighted dissimilarity is
\begin{equation}
 d(\mathbf{x},\mathbf{y}) =
 \frac{\displaystyle\sum_{\text{comparable features}}
       \text{weight}\times\text{difference}}
      {\displaystyle\sum_{\text{comparable features}}\text{weight}}.
 \label{eq:gower:definition}
\end{equation}
Numeric difference is the absolute difference divided by that feature's
observed training range. Nominal and symmetric binary differences are zero
for equality and one otherwise. An asymmetric binary feature uses the same
difference but excludes joint zeros from both sums. Missing observations
also exclude the feature for that pair. Feature weights are finite,
non-negative and not all zero; zero-weight features are inactive.

The following choices complete the implementation's domain. A numeric
feature with zero training range, or any entirely unobserved training
column, is excluded globally. Query batches do not recompute ranges or
reactivate columns. Numeric differences larger than the fitted range
saturate at one, an explicit extension for new observations. A zero
denominator raises an error for non-identical vectors. Identical vectors,
including matching missing positions, receive zero by convention; no
off-diagonal distance is invented for unequal vectors with no overlap.

Ordinal columns require an explicit increasing sequence of levels.
Their contribution is the difference in level positions divided by the
number of intervals in that sequence. Unknown levels are rejected and a
single-level feature is excluded. Equally spaced level positions are a
modelling assumption. Podani (1999), \emph{Taxon} 48(2), 331--340,
\href{https://doi.org/10.2307/1224438}{doi:10.2307/1224438}, distinguishes
ordinal extensions; this implementation does not claim his empirical-rank
tie correction.

\paragraph{Properties}
\label{sec:measure:gower:properties}
Every returned contribution lies in $[0,1]$, so its non-negative weighted
mean does too. Availability and contributions are symmetric, and
$d(\mathbf{x},\mathbf{x})=0$. The declarations are therefore
\texttt{bounded=(0.0, 1.0)} and \texttt{is\_symmetric=True}.
However, the separation and triangle axioms in Rudin's definition of a
metric~\cite[Ch.~2, Def.~2.15]{ref_8} need not hold when comparisons use
different subsets of features.

For a reproducible counterexample, fit on
$(0,0,\text{missing})$, $(0,\text{missing},0)$,
$(\text{missing},1,0)$ and $(1,1,1)$.
The fourth row establishes unit ranges. The first-to-second and
second-to-third dissimilarities are zero, but the first-to-third
dissimilarity is one. Thus distinct incomplete vectors can have zero
dissimilarity and $1>0+0$ violates the triangle inequality.
Consequently \texttt{is\_metric=False} is necessary. This is a statement
about the general supported domain; it does not assert that every
complete-data special case fails to be metric. Ward additionally requires
Euclidean geometry: being metric alone would not make an arbitrary
measure suitable for Ward.

\paragraph{Applicability}
\label{sec:measure:gower:applicability}
The class declares \texttt{accepts\_missing=True} and
\texttt{accepts\_categorical=True}, with matching capability tags.
Types are supplied per column; numeric-looking category codes are not
silently interpreted as measurements. Binary values must be 0/1 or
booleans. Missing sentinels are normalised without filling measurements;
infinities, complex values and sparse matrices are rejected.
Average-linkage clustering can consume the resulting matrix through
\texttt{metric="precomputed"}. The
\href{https://scikit-learn.org/stable/modules/generated/sklearn.cluster.AgglomerativeClustering.html}{scikit-learn API}
documents this route and restricts Ward to Euclidean input.
Data with no comparable positive-weight information between unequal rows
fall outside the defined domain and are refused before clustering.

\paragraph{Computation and complexity}
\label{sec:measure:gower:complexity}
\texttt{Gower} inherits \texttt{BaseDissimilarity.fit}; its \texttt{\_fit}
learns ranges and active features in $\mathcal{O}(mn)$ time.
Constructor parameters remain unchanged and fitted state is declared
through \texttt{\_required\_fitted}. A local validation hook permits mixed
values while preserving scikit-learn's dimension and feature-name checks;
the common base otherwise requests numeric input.
\texttt{pairwise} iterates over features and broadcasts all observation
pairs in NumPy. It does not call the scalar method in nested observation
loops. \texttt{\_\_call\_\_} delegates to the matrix path. A square matrix
costs $\mathcal{O}(m^2n)$ time and $\mathcal{O}(m^2+mn)$ space; rectangular
evaluation replaces $m^2$ by the product of the two row counts. No
three-dimensional observation-pair-by-feature tensor is allocated.
Dense quadratic storage remains the main scaling constraint.

\paragraph{Application to \projectname{} data}
\label{sec:measure:gower:application}
\path{notebooks/05-gower.ipynb} uses the ten-section evidence template.
Its \GowerRows{} rows are a seeded synthetic fixture, not operational
\projectname{} records. An explicit \texttt{FrameLoader} schema separates
identifiers and planted interpretation labels from six modelling columns:
pH, turbidity, source type, ordered priority, an asymmetric alarm and a
constant probe. The constant probe is inactive. There are
\GowerMissing{} missing modelling cells (\GowerMissingPercent\%);
all remain missing after clustering. pH is always observed, deliberately
ensuring pairwise coverage. Equal weights and seed 42 are fixed before
selection. No imputer, one-hot encoder or external scaler is used.

The protocol reports silhouette and sweeps two to ten clusters.
Average linkage is fitted using the real scikit-learn backend because this
checkout has no concrete precomputed \texttt{xxcluster} clusterer.
Silhouette is explicitly evaluated with \texttt{metric="precomputed"}:
the current \texttt{ComparisonRun} does not forward that argument and
would otherwise score Euclidean distances between matrix rows.
Results are recorded as a \texttt{RunResult} and exported with the shared
\texttt{ComparisonTable}. Ten seeded 80\% subsamples repeat both range
fitting and cluster-count selection inside each sample; this explicit
procedure replaces the currently unimplemented stability component.

\paragraph{Behaviour}
\label{sec:measure:gower:behaviour}
Independent hand calculations test numeric, categorical and weighted
contributions. One example gives dissimilarity $0.5$ when a binary joint
absence is counted, versus $1.0$ when it is excluded. Tests also check
missing-weight removal, ordinal ordering, rectangular consistency,
unchanged inputs and invariance to query-batch composition.
All applicable scikit-learn estimator checks pass without exclusions.

On the synthetic fixture, selection chooses \GowerSelectedK{} clusters
with Gower silhouette \GowerSilhouette{}. Supplementary agreement with
the held-back planted labels is adjusted Rand index \GowerPlantedARI{}.
The resampling adjusted Rand index has mean \GowerStabilityMean{} and
sample standard deviation \GowerStabilitySD{}, with
\GowerStabilityFailures{} failed resamples. These values are generated
by the notebook, including the less-than-perfect resampling agreement.

\paragraph{Limitations}
\label{sec:measure:gower:limitations}
Pair-dependent missingness can make unlike rows appear identical on the
available information. The synthetic missingness mechanism and fully
observed pH column make this a controlled demonstration, not validation
on arbitrary operational gaps. Same-data silhouette is a selection score,
not an independent generalisation estimate, and subsampling agreement
does not establish stable operational regimes. Constant-feature exclusion
can conceal new variation until refitting; range saturation discards the
magnitude of extreme query differences. Ordinal rank spacing and binary
absence semantics need domain justification. Dense storage limits scale.

The backend Ward rejection test passes, but no concrete Task 40 Ward
component or \texttt{is\_metric} guard exists in this checkout. Its separate
integration test is explicitly skipped until registration; the backend
error is not reported as proof of that guard. All notebook cells executed
in a fresh in-process IPython session with captured outputs because the
environment blocks Jupyter sockets. A normal project-kernel restart/run

\label{sec:measure:gower:summary}

and incomplete observations without filling missing measurements. The
